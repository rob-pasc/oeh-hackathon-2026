# demo

Scan JSON files and pre-generated caches for the seeded demo devices on the public deployment ([feature 005](../docs/features/feature-005-public-demo-deployment/PLAN.md)). They let demo reports render without live LLM calls.

The selected models are the ThinkPad T480, XPS 13 9360 and EliteBook 840 G5. Real scan files, caches and the seed command are pending.
