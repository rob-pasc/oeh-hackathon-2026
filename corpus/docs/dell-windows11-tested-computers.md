# Dell Computers Tested for Update to Windows 11 (Dell knowledge base article 000187485)

## Summary

This article lists Dell computers that have previously been tested for upgrade from Windows 10 to Windows 11, and to update from Windows 11 to Windows 11 2022 Update (build 22H2).

Use the PC Health Check app to see if your computer meets the minimum requirements to run Windows 11.

To satisfy regulatory requirements, computer models marked below with an asterisk [...] do NOT meet TPM requirements if they were shipped to the People's Republic of China.

Beginning with Windows 11 Build 23H2, Dell will not provide a list of update testing between versions of Windows 11.
