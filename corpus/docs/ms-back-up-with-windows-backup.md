# Back up and restore with Windows Backup (Microsoft Support)

[Extract of the Windows 11 tab of the article.]

## Back up your PC

### Step 1: Sign in with a Microsoft account

This is the account associated with Windows, Microsoft 365, OneDrive, Xbox, and more. Your backed-up information will be stored with your Microsoft account, so getting back to your things on a new PC is as easy as signing in.

In the Settings app on your Windows device, select Accounts > Your info

Select Sign in with a Microsoft account instead. You'll see this only if you're using a local account.

### Step 2: Back up your folders

Your free Microsoft account comes with 5 GB of OneDrive cloud storage [...] and backing up your folders syncs the folders you specify to your OneDrive account

To open Windows Backup, search for it in the Start menu:

Select Start

Type backup, and select Windows Backup from the results

Expand Folders, and select which of your user folders you want to back up to OneDrive. You can back up your Desktop, Documents, Pictures, Videos, and Music folders by toggling the switch for each folder to On

### Step 3: Back up your settings and preferences

Once you have everything set up the way you want it, select Back up.

If you receive an error from OneDrive when you try to back up, it's possible that you aren't signed in to OneDrive, have insufficient storage, or there may be another issue with OneDrive that needs to be resolved for Windows Backup to work.

### Step 4: Time to relax!

If you want to check and make sure everything is still backed up, you can open the Windows Backup app and it will display the current state of your backup.

## Restore your PC

### How do I restore a backup?

When you get a new PC or if you have to reinstall Windows, when you are setting it up, just log in with the same Microsoft account that you used to make the backup here. We'll see that you have backups and ask you if you would like to restore one.

Files can be restored anytime by signing in to OneDrive with the same Microsoft account you used to make the original backup
