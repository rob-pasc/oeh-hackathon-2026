# Windows 10 Consumer Extended Security Updates (ESU) (Microsoft Österreich)

## Was ist Windows ESU?

Das Programm für erweiterte Sicherheitsupdates (ESU) für Windows 10 bietet Kunden eine sicherere Option, ihre Windows 10-PCs auch nach dem 14. Oktober 2025 weiter zu verwenden, während sie auf Windows 11. Das ESU-Programm trägt dazu bei, das Risiko von Schadsoftware- und Cybersicherheitsangriffen zu verringern, indem es Zugriff auf kritische und wichtige Sicherheitsupdates bietet gemäß Definition des Microsoft Security Response Center (MSRC) für Geräte mit Windows 10, Version 22H2.

Die ESU-Registrierung bietet keine anderen Arten von Korrekturen, Funktionsverbesserungen oder Produkterweiterungen. Es wird auch kein technischer Support bereitgestellt.

Der Support für Windows 10 ist zu Ende. Sie können sich jederzeit bis zum Ende des Programms am 12. Oktober 2027 für ESU registrieren. Wenn Sie bereits registriert sind, wird Ihre Abdeckung bis zu diesem Datum automatisch fortgesetzt–keine Aktion erforderlich.

## Voraussetzungen für Windows 10 ESU

- Auf den Geräten muss Windows 10, Version 22H2 Home, Professional, Pro Education oder Workstations Edition laufen.
- Auf den Geräten muss das neueste Windows-Update installiert sein.
- Das Vorbereitungspaket für die Lizenzierung von ESU für Windows 10, KB5126256, ist erforderlich.
- Das Konto, mit dem Sie sich am Gerät anmelden, muss ein Administratorkonto sein.
- Bei dem Microsoft-Konto kann es sich nicht um ein Kinderkonto handeln.

## Wie viel kostet Windows 10 ESU?

Verbraucher im Europäischen Wirtschaftsraum können sich auf eine der folgenden Arten für ESU registrieren, nachdem sie sich mit einem Microsoft-Konto angemeldet haben:

- Benutzer, die mit einem Microsoft-Konto auf dem geeigneten PC angemeldet bleiben: Ein Microsoft-Konto, mit dem Sie sich beim ESU-Registrierungstool anmelden, wird erweiterte Sicherheitsupdates auf dem Gerät bis zum 12. Oktober 2027 ermöglichen, solange Sie sich weiterhin mit Ihrem Microsoft-Konto bei Windows anmelden, das Sie für die Registrierung verwendet haben. Wenn Sie sich nicht weiterhin mit Ihrem Microsoft-Konto bei Ihrem PC anmelden, werden ESU-Updates für Ihr Gerät nach einem Zeitraum von bis zu 60 Tagen eingestellt.
- Benutzer mit einem lokalen Konto, die nicht mit einem Microsoft-Konto auf dem geeigneten PC angemeldet bleiben möchten: Ein einmaliger Kauf von $30 USD oder dem Gegenwert in der Landeswährung zuzüglich anfallender Steuern.
