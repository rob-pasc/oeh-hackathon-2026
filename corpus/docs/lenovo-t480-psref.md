# ThinkPad T480 Platform Specifications (PSREF)

<!-- page: 1 -->
## Processor

7th Generation Intel Core i5 Processor
i5-7200U: 2 cores, 4 threads, 2.5 GHz base, 3.1 GHz max turbo, 3MB cache, DDR4-2133, Intel HD Graphics 620
i5-7300U: 2 cores, 4 threads, 2.6 GHz base, 3.5 GHz max turbo, 3MB cache, DDR4-2133, Intel HD Graphics 620

or 8th Generation Intel Core i3 / i5 / i7 Processor
i3-8130U: 2 cores, 4 threads, 2.2 GHz base, 3.4 GHz max turbo, 4MB cache
i5-8250U: 4 cores, 8 threads, 1.6 GHz base, 3.4 GHz max turbo, 6MB cache, DDR4-2400, Intel UHD Graphics 620
i5-8350U: 4 cores, 8 threads, 1.7 GHz base, 3.6 GHz max turbo, 6MB cache, DDR4-2400, Intel UHD Graphics 620
i7-8550U: 4 cores, 8 threads, 1.8 GHz base, 4.0 GHz max turbo, 8MB cache, DDR4-2400, Intel UHD Graphics 620
i7-8650U: 4 cores, 8 threads, 1.9 GHz base, 4.2 GHz max turbo, 8MB cache, DDR4-2400, Intel UHD Graphics 620

## Graphics

Intel HD Graphics 620 or Intel UHD Graphics 620 in processor only or Intel HD Graphics 620 or Intel UHD Graphics 620 in processor and NVIDIA GeForce MX150, 2GB GDDR5 memory (discrete graphics is available only on i7 models in EMEA)

## Memory

32GB max / 2400MHz DDR4, dual-channel capable, two DDR4 SO-DIMM sockets
* System clocks down for processors with lower memory controller

## Storage

System has one HDD slot or one M.2 2280 slot exclusively for storage
Some: HDD / SATA 6.0Gb/s, 2.5" wide, 7mm high, Active Protection System
Some: SSD / SATA 6.0Gb/s, 2.5" wide, 7mm high (e.g. xxxGB SSD)
Some: M.2 SSD / PCIe NVMe, PCIe 3.0 x 4
Some: 128GB M.2 SSD / PCIe NVMe, PCIe 3.0 x 2, in WWAN slot as 2nd Storage, mutually exclusive with WWAN
* Installed M.2 SSD is PCIe 3.0 x 4 but run at PCIe 3.0 x 2 due to M.2 SSD adapter limitation

## Optane memory

Intel Optane memory, PCIe NVMe, PCIe 3.0 x 2

## Battery

Optional integrated Li-ion 24Wh battery and external Li-ion 24Wh, 48Wh, or 72Wh battery

## Max battery life

Max battery life (MobileMark 2014): Integrated model: 24Wh 7.2 hr; 48Wh 14.4 hr; 72Wh 21.8 hr; 24Wh + 24Wh 14.4 hr; 24Wh + 48Wh 21.8 hr; 24Wh + 72Wh 29.0 hr
Discrete model: 24Wh 6.6 hr; 48Wh 13.2 hr; 72Wh 19.8 hr; 24Wh + 24Wh 13.6 hr; 24Wh + 48Wh 19.8 hr; 24Wh + 72Wh 26.4 hr
* Battery life varies significantly with hardware configurations, settings, usage, & other factors

## AC adapter

45W or 65W USB-C AC adapter

## Operating system

Optional: Windows 10 Home 64 or Windows 10 Pro 64

## Security chip

Discrete TPM 2.0, TCG Certified (may be disabled in some region)

## Keyboard

6-row, spill-resistant, multimedia Fn keys, optional LED backlight

## Display

Some: 14.0" (355mm) HD (1366x768), anti-glare, LED backlight, 220 nits, 16:9 aspect ratio, 400:1 contrast ratio
Some: 14.0" (355mm) FHD (1920x1080), anti-glare, LED backlight, WVA, 250 nits, 16:9 aspect ratio, 700:1 contrast ratio, 170° viewing angle
Some: 14.0" (355mm) WQHD (2560x1440), anti-glare, LED backlight, WVA, 300 nits, 16:9 aspect ratio, 700:1 contrast ratio, 72% gamut, 170° viewing angle

## Limited warranty

• 1-year/3-yr battery depot repair service
• 3-year/3-yr battery limited onsite service

## Environment

EPEAT Gold (US only); ENERGY STAR 6.1; RoHS-compliant

Note: The specifications above may not be available in all regions and might change by regions.
