# corpus

Curated knowledge base for retrieval ([feature 002](../docs/features/feature-002-knowledge-base-retrieval/PLAN.md)): `manifest.yaml`, which holds the source, terms/licence note and model applicability for each document, plus document extracts in `docs/`.

Only add documents whose terms allow our use, and record the basis in the manifest. Not populated yet; the demo models are still undecided.
