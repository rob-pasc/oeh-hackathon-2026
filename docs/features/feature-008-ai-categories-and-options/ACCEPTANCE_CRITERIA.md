- **2026-11-21, live demo review (AC-016).** `npm run categories:smoke -w server` against the real corpus index (31 documents, 197 passages) and DeepSeek. Scans were the fictional example laptop with each model's identity, CPU, RAM layout and a worn battery, because no real scans of the demo models exist yet (`demo/README.md`). Office use, one run per model; all three had model-specific evidence; each call took about 10–11 s (deadline 40 s).
  - **T480:** battery (professional, Depends), hand it down (two options), "Upgrade to Windows 11" (AI estimate), recycle and salvage. No owner battery work.
  - **XPS 13 9360:** professional battery replacement, a repair-subsidy check (AI estimate), hand it down, "Skip SSD and RAM upgrades" (Not a fit, soldered memory), extended Windows 10 updates (AI estimate), salvage and recycle. No fitting RAM option.
  - **EliteBook 840 G5:** professional battery replacement, reinstall and Windows 11 (AI estimates), hand it down, a larger SSD and a second RAM module (both Depends), salvage and recycle. No owner battery work.
  - **Observations, not failures:** the AI sometimes adds a "skip upgrades" option as Not a fit; a reason mentioned "50%" of repair costs, which is allowed as it is not a euro or CO₂e figure. The first smoke run reused one device ID for all models and so served the T480 answer three times from the cache; the script was fixed, and only the second run counts.
  - **Limits:** synthetic scans, office use only, a single sample per model. Rerun with real scans when they exist.
- **2026-11-21, browser check (AC-008 to AC-011, AC-015).** Headless Chromium (Playwright's chrome-headless-shell 1255) driven over the DevTools protocol against `VITE_API_MODE=mock npx vite`, with reduced motion so the counting animation shows final values.
