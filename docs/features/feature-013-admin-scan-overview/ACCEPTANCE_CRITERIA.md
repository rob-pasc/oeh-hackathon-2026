## Review and integration evidence

Completion boundary: locally verified handoff with self-review on `feat/adminpage`, then a check on the deployed site after release ([plan](./PLAN.md#review-and-integration)).

**2026-11-21, self-review** by the implementing agent (not independent) of `b17b335..HEAD` on `feat/adminpage`, against the plan, with authentication, sessions, rate limits and logging checked in particular:

- Credentials: both SHA-256 digests are always compared with `timingSafeEqual` (no early return between username and password). The password length check counts characters, and the warning contains neither the password nor its length. No finding.
- Sessions: 32 random bytes per token, kept in a `Map` in memory only; expired tokens are removed on access and on each new login. The cookie is scoped to `/api/admin`, so the web page and other routes never receive it. No finding.
- Rate limits: the check runs before the credentials are read; once the global limit is reached, failed attempts are no longer recorded, so the per-client map cannot grow without bound during an attack. No finding.
- Logging and caching: the production request serializer logs only the method and route pattern; every admin response is `no-store` and `noindex`. No finding.
- Note, not fixed (outside scope): the `/admin` page can be shown inside a frame on another site, because the web server sends no `frame-ancestors` policy. The page is read-only, so the risk is low; a `Content-Security-Policy: frame-ancestors 'none'` header in `web/nginx.conf` would close it.
- Note, not fixed (development only): Safari may not keep a `Secure` cookie on `http://localhost`. If a local login does not stick in Safari, use Chrome or Firefox locally; production uses HTTPS.
- Note: the sample login for mock mode (`admin` / `sample-admin-password`) is part of the web bundle. The live server never accepts it, so it grants nothing.

Checks: `npm run typecheck`, `npm test` (shared 124, server 344, web 131) and `npm run build` pass. CI has not run on this branch.
