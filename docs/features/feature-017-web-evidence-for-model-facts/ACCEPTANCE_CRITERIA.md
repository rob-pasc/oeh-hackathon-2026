## Review and integration evidence

Completion boundary: locally verified, merged into `main`, live smoke run (see the [plan](./PLAN.md#review-and-integration)). Release to leaaf.green is outside this boundary.

**Self-review, 2026-11-22, by Claude (not independent).** Reviewed revision: f1331e6 and d3c9256 on `main`, plus the working tree of the documentation commit. Checked against FR-001 to FR-015 and the exclusions.

| Finding | Resolution |
|---|---|
| Battery rule: a `battery_user_replaceable: true` fact citing a web page *and* a generic corpus passage (for example a general battery safety page) passed, because the rule only dropped facts supported by web pages alone. A generic page cannot establish replaceability for one model. | Fixed: with a web citation, the fact now needs a curated passage about the exact model; tests added. FR-006 clarified in the plan, pending the user's confirmation. |
| Query privacy: queries are built only from the manufacturer (company suffix removed), the model name and fixed topic words; logs carry provider name and error kind, never query text or keys. | No change needed; covered by AC-013. |
| Model match: whole-token match on title or text, separators interchangeable, nothing alphanumeric after the last token; names without a digit are not searched, so a bare "Latitude" cannot match. | No change needed. Residual risk: a page that names the model but describes another configuration; mitigated by the LLM confirmation and the label. |
| Prompt injection from page text: page text reaches the LLM only as passage data inside the existing delimiters; the answer is schema-validated and citations are checked against retrieved IDs. | No change needed. |
| A request that joins a search already running for the same model gets no `status` event, so its page shows the rotating phrases instead of "Searching the web…". | Accepted as minor; noted in the plan. |
| Default deadline of 8 s (proposal) would cut LangSearch off at its 4 s share. | Changed to 20 s before commit; recorded in the plan. |
| Behavior beyond the written requirements: confidence drops one level with web-only evidence. | Recorded as FR-015 with AC-019, pending the user's confirmation. |

CI: not run (not pushed). Merge: the work is committed directly on `main`, as the team works without pull requests.
